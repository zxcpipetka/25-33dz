# HW-29-react — Книга контактів

Застосунок для збереження та пошуку контактів. Redux Persist зберігає список контактів у браузері.

## Запуск локально

```sh
npm install
npm start
```

Застосунок відкриється за адресою `http://localhost:3000`.

## Стек

- React та CSS Modules
- Redux Toolkit і React Redux
- Redux Persist: зберігається список контактів, фільтр залишається тимчасовим

## Деплой

GitHub Actions збирає та публікує застосунок у гілку `gh-pages` після оновлення `main`.
